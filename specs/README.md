# Especificações

As especificações seguem a convenção do [Spec-Kit](https://github.com/github/spec-kit): uma pasta por funcionalidade, numerada.

```text
specs/
└── 001-nome-da-funcionalidade/
    ├── spec.md    # Histórias de usuário (INVEST) e critérios de aceite Dado / Quando / Então
    ├── plan.md    # Plano técnico
    └── tasks.md   # Tarefas para o agente
```

Esta pasta substitui `docs/specs/` do esqueleto do bootcamp. As histórias com critérios de aceite são entrega do checkpoint 02. Escreva tudo em português do Brasil.
